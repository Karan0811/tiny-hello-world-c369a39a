# Web Scraping Cheat Sheet

| Concept | Purpose |
|---------|---------|
| requests.get() | Download HTML |
| BeautifulSoup() | Parse HTML |
| find() | First matching element |
| find_all() | All matching elements |
| select() | CSS selector search |
| .text | Extract element text |
| ["href"] | Read HTML attributes |
| time.sleep() | Rate limiting |
