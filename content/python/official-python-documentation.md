# Official Python Documentation Library

## Core references

- [Python Documentation](https://docs.python.org/3/) — language, tutorial, library, HOWTOs, FAQ, installation, and C API.
- [Python Tutorial](https://docs.python.org/3/tutorial/) — the official guided path from basics through modules, files, errors, and classes.
- [Language Reference](https://docs.python.org/3/reference/) — definitive syntax and semantics.
- [Standard Library](https://docs.python.org/3/library/) — built-in modules including `pathlib`, `json`, `logging`, `asyncio`, `typing`, and `sqlite3`.
- [HOWTO Guides](https://docs.python.org/3/howto/) — focused guides for logging, regex, Unicode, sorting, and functional programming.
- [FAQ](https://docs.python.org/3/faq/) and [Glossary](https://docs.python.org/3/glossary.html) — terminology and common design questions.
- [Module Index](https://docs.python.org/3/py-modindex.html) and [General Index](https://docs.python.org/3/genindex.html) — fast reference discovery.

## Ecosystem references

- [Python Packaging User Guide](https://packaging.python.org/) — environments, wheels, build, publishing, and dependency management.
- [Python Developer’s Guide](https://devguide.python.org/) — CPython contribution, testing, and internals.
- [Typing documentation](https://typing.python.org/) — generics, protocols, `TypedDict`, `Literal`, and overloads.

## Essential PEPs

- [PEP 8](https://peps.python.org/pep-0008/) — style.
- [PEP 20](https://peps.python.org/pep-0020/) — the Zen of Python.
- [PEP 257](https://peps.python.org/pep-0257/) — docstrings.
- [PEP 484](https://peps.python.org/pep-0484/), [PEP 526](https://peps.python.org/pep-0526/), [PEP 544](https://peps.python.org/pep-0544/), [PEP 557](https://peps.python.org/pep-0557/), [PEP 585](https://peps.python.org/pep-0585/), [PEP 604](https://peps.python.org/pep-0604/) — modern typing and data models.
- [PEP index](https://peps.python.org/) — authoritative design history and specifications.
