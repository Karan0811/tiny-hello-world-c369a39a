|------|------|

| Start Thread | `thread.start()` |
| Join Thread | `thread.join()` |
| Create Lock | `threading.Lock()` |
| Create Process | `Process(target=func)` |
| Thread Pool | `ThreadPoolExecutor()` |
| Process Pool | `ProcessPoolExecutor()` |
| Critical Section | `with lock:` |
