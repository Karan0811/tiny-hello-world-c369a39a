# Decorators Cheat Sheet

| Concept | Description |
|---------|-------------|
| @decorator | Apply a decorator |
| *args | Variable positional arguments |
| **kwargs | Variable keyword arguments |
| functools.wraps | Preserve metadata |
| @staticmethod | Instance-independent method |
| @classmethod | Class-aware method |
| @property | Attribute-like method |
| Parameterized Decorator | Decorator with arguments |
