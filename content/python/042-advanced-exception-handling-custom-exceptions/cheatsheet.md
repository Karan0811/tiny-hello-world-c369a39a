# Advanced Exception Handling Cheat Sheet

| Concept | Description |
|---------|-------------|
| raise | Explicitly raise an exception |
| Custom Exception | Domain-specific exception |
| raise ... from ... | Exception chaining |
| raise | Re-raise current exception |
| assert | Debugging assertion |
| logging.exception() | Log traceback |
| finally | Always execute cleanup |
| Exception Hierarchy | Organize related exceptions |
