# Iterators & Generators Cheat Sheet

| Concept | Description |
|---------|-------------|
| iter() | Creates an iterator |
| next() | Returns the next value |
| yield | Produces a value and pauses execution |
| Generator Expression | (x for x in iterable) |
| Lazy Evaluation | Compute values only when needed |
| send() | Send a value into a generator |
| throw() | Raise an exception inside a generator |
| close() | Stop a generator |
