# Context Managers Cheat Sheet

| Concept | Description |
|---------|-------------|
| with | Automatically manage resources |
| __enter__() | Acquire resource |
| __exit__() | Release resource |
| contextlib | Context manager utilities |
| @contextmanager | Generator-based context manager |
| yield | Separates setup and cleanup |
| Multiple with | Manage multiple resources |
| Nested with | Nested resource management |
