# Python Logging Cheat Sheet

| Task | Class / Method |
|---|---|
| Console Logging | StreamHandler |
| File Logging | FileHandler |
| Rotate by Size | RotatingFileHandler |
| Rotate by Time | TimedRotatingFileHandler |
| Get Logger | logging.getLogger(__name__) |
| Exception Logging | logging.exception() |
| Config from File | logging.config.fileConfig() |
| Set Formatter | handler.setFormatter() |
