# Python Internals Cheat Sheet

| Concept | Description |
|---------|-------------|
| LEGB | Local → Enclosing → Global → Built-in |
| global | Modify global variable |
| nonlocal | Modify enclosing variable |
| Namespace | Mapping of names to objects |
| Scope | Region where names are visible |
| Bytecode | Intermediate compiled instructions |
| dis | View Python bytecode |
| PVM | Executes Python bytecode |
