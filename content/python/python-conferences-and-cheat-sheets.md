# Python Conferences, Cheat Sheets, and Reference Collections

- [PyCon US](https://us.pycon.org/), [EuroPython](https://ep2026.europython.eu/), [PyData](https://pydata.org/), [PyCon India](https://in.pycon.org/), and [SciPy](https://www.scipy.org/) provide talks, tutorials, and community connections.
- [PyVideo](https://pyvideo.org/) indexes recorded Python talks.
- Prefer the [official Python documentation](https://docs.python.org/3/) for durable syntax and standard-library reference.
- Use [Awesome Python](https://github.com/vinta/awesome-python) for curated project discovery and [The Algorithms – Python](https://github.com/TheAlgorithms/Python) for algorithm study.
- Keep one official documentation tab, one project-quality reference, and one practice platform in your regular learning workflow.
