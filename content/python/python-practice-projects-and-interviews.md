# Python Practice, Projects, and Interview Preparation

## Practice

- [Exercism Python](https://exercism.org/tracks/python) for mentor-supported language practice.
- [HackerRank Python](https://www.hackerrank.com/domains/python), [LeetCode](https://leetcode.com/), [Codewars](https://www.codewars.com/), [Project Euler](https://projecteuler.net/), [CSES](https://cses.fi/problemset/), and [AtCoder](https://atcoder.jp/).
- [CS50P](https://cs50.harvard.edu/python/), [Kaggle Learn](https://www.kaggle.com/learn), and [Google’s Python Class](https://developers.google.com/edu/python).

## Project ladder

Build a calculator, todo CLI, password generator, file organizer, and expense tracker first. Progress to an API, weather dashboard, URL shortener, chat application, web scraper, task scheduler, production CLI, and AI chatbot.

## Interviews

Master core types, mutability, identity, comprehensions, functions, OOP, generators, decorators, context managers, exceptions, typing, the GIL, async/threading/multiprocessing, and testing. Use [Tech Interview Handbook](https://www.techinterviewhandbook.org/) and [NeetCode](https://neetcode.io/) for structured interview practice. Practice explaining code aloud, debugging, refactoring, and writing tests under a time limit.
