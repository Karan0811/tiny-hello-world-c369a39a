# Python CLI Cheat Sheet

| Concept | Purpose |
|---------|---------|
| argparse | Parse command-line arguments |
| Positional Arguments | Required inputs |
| Optional Arguments | Named options (`--`) |
| Subcommands | Multiple operations |
| os.getenv() | Read environment variables |
| logging | Application logging |
| pyproject.toml | Package configuration |
| Entry Points | Executable CLI commands |
