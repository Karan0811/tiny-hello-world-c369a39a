# Type Hints Cheat Sheet

| Feature | Example |
|---------|---------|
| Variable | `age: int = 20` |
| Function | `def greet(name: str) -> str:` |
| List | `list[int]` |
| Dict | `dict[str, int]` |
| Optional | `str | None` |
| Union | `int | float` |
| Literal | `Literal["train", "test"]` |
| TypedDict | `class User(TypedDict):` |
| Generic | `TypeVar("T")` |
| MyPy | `mypy app.py` |
