|---|---|

| Build | python -m build |
| Upload | twine upload |
| Test Repository | TestPyPI |
| Public Repository | PyPI |
| Editable Install | pip install -e . |
| Local Install | pip install . |
| Wheel | .whl |
| Source Distribution | .tar.gz |
| CLI Entry Points | [project.scripts] |
