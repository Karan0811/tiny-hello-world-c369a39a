# Python Tools and Career Roadmap

## Professional toolkit

Use VS Code or PyCharm; Git and GitHub; `venv`, pip, uv, or Poetry; Ruff and Black; pytest; pre-commit; Docker; and a debugger such as pdb or debugpy. Use JupyterLab for data and AI work. Add mypy or pyright for static analysis, coverage.py for tests, and cProfile or py-spy for performance work.

## Career paths

- **Backend:** APIs, SQL, Docker, tests, deployment.
- **Automation:** files, browser automation, scheduling, and APIs.
- **Data/ML:** NumPy, pandas, scikit-learn, and notebooks.
- **AI engineering:** Python, APIs, model providers, vector search, evaluation, and deployment.

## Portfolio progression

Begin with small CLI and automation tools; then publish tested APIs and database-backed applications; finally build a deployed capstone with documentation, CI, observability, and a well-explained README. Contribute documentation, tests, or small fixes to established open-source projects before pursuing larger features.
