# Python Books Library

## Beginner

- **Python Crash Course** — Eric Matthes; foundation plus projects.
- **Automate the Boring Stuff with Python** — Al Sweigart; practical automation.
- **Think Python (2nd Edition)** — Allen B. Downey; problem-solving first.
- **Invent Your Own Computer Games with Python** — Al Sweigart; fundamentals through games.
- **Head First Python (2nd Edition)** — Paul Barry; visual, exercise-led learning.

## Intermediate

- **Python Tricks** — Dan Bader; idiomatic patterns.
- **Effective Python (2nd Edition)** — Brett Slatkin; maintainable production practices.
- **Python Cookbook (3rd Edition)** — David Beazley and Brian K. Jones; reusable recipes.
- **Serious Python** — Julien Danjou; testing, packaging, deployment, and performance.
- **Robust Python** — Patrick Viafore; typing, defensive programming, and testing.

## Advanced

- **Fluent Python (2nd Edition)** — Luciano Ramalho; data model, concurrency, descriptors, and metaprogramming.
- **High Performance Python (2nd Edition)** — Micha Gorelick and Ian Ozsvald; profiling and parallelism.
- **Architecture Patterns with Python** — Harry Percival and Bob Gregory; DDD and dependency inversion.
- **CPython Internals** — Anthony Shaw; bytecode, memory, and interpreter behavior.
- **Expert Python Programming** — Michał Jaworski and Tarek Ziadé; production engineering.

## Reading path

Start with *Python Crash Course* or *Think Python*, add *Automate the Boring Stuff*, then *Effective Python*. Move to *Fluent Python* and *Architecture Patterns with Python* when production design and advanced language features become relevant.
