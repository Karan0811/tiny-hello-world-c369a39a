# Regex Cheat Sheet

| Pattern | Meaning |
|---------|---------|
| \d | Digit |
| \w | Word character |
| \s | Whitespace |
| [] | Character class |
| * | Zero or more |
| + | One or more |
| ? | Optional |
| {n,m} | Repetition range |
| ^ | Start of string |
| $ | End of string |
| \b | Word boundary |
| re.compile() | Precompile Regex patterns |
