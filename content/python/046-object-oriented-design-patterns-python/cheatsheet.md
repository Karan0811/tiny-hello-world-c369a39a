# Object-Oriented Design Patterns Cheat Sheet

| Pattern / Principle | Purpose |
|---------------------|---------|
| SRP | One responsibility per class |
| OCP | Open for extension, closed for modification |
| LSP | Subclasses should be substitutable |
| ISP | Small, focused interfaces |
| DIP | Depend on abstractions |
| Singleton | One shared instance |
| Factory Method | Centralized object creation |
| Strategy | Runtime algorithm selection |
| Observer | Notify subscribers of changes |
| Dependency Injection | Inject dependencies externally |
