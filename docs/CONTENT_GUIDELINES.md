# AI University Content Guidelines

## Mission

AI University is a complete learning platform.

Students should not need external tutorials after studying a lesson.

Content must teach concepts from beginner to production level.

Quality is always more important than quantity.

---

## Teaching Philosophy

Every lesson must:

- Start from first principles
- Build intuition before syntax
- Use practical examples
- Connect theory to production
- Avoid memorization-based teaching

---

## Audience

Target audience:

- Complete Beginners
- College Students
- Working Professionals
- AI Engineers

Assume zero prior knowledge unless prerequisites specify otherwise.

---

## Lesson Goals

Each lesson should enable students to:

- Understand the concept
- Explain it
- Apply it
- Debug it
- Use it in real projects

---

## Code Rules

Every code snippet must:

- Compile
- Run
- Follow best practices
- Be production quality
- Include comments only when useful

Never include broken code.

---

## Diagrams

Use Mermaid only when it improves understanding.

Avoid unnecessary diagrams.

---

## Examples

Use realistic examples instead of toy examples.

Prefer:

- ML pipelines
- APIs
- AI systems
- Data processing
- Production workflows

---

## Quality Checklist

Before finishing every lesson verify:

✓ Accurate
✓ Beginner friendly
✓ Technically correct
✓ No repetition
✓ No placeholders
✓ No "Coming Soon"
✓ Runnable code
✓ Production practices included
