# Changelog

All notable milestones for AI University.

The format is loosely based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

---

## [0.5.0] — Python vertical slice + documentation

### Added
- Python landing page at `/learning/python` — overview, journey, modules, projects preview, revision, resources, Ask AI.
- `src/config/python.ts` with 20 modules, 8 project stubs, resource sections, and AI action list.
- `src/features/python/components/` — 9 reusable, config-driven components.
- `/docs` folder: README, ARCHITECTURE, SYSTEM_DESIGN, FEATURES, CHANGELOG, DECISIONS, FOLDER_STRUCTURE, DATA_MODELS.

## [0.4.0] — AI Core architecture

### Added
- Provider-agnostic AI layer under `src/features/ai/`.
- Registry, adapter interface, prompt templates, context provider, mentor hook.
- 10 reusable AI UI components.

## [0.3.0] — Learning Engine

### Added
- Learning types, config, and 13 reusable components.
- Category, module, and lesson routes with deep tab structure.

## [0.2.0] — Roadmap + Projects engines

### Added
- Roadmap tracks with canvas and skill tree.
- Project catalog with filters and detail tabs.

## [0.1.0] — Foundation

### Added
- App shell, sidebar, top bar, command palette, theme, routing.
- Shared UI primitives.
