# AI University Curriculum Map

## Overview

This document defines the complete curriculum structure for AI University.

It is the single source of truth for all learning modules.

All generated lessons must follow this order unless explicitly instructed otherwise.

---

# Generation Rules

- Generate modules sequentially.
- Complete one module before starting the next.
- Never regenerate completed lessons.
- Continue from the first unfinished lesson.
- Never skip lessons.
- Every lesson must follow:
  - CONTENT_GUIDELINES.md
  - LESSON_TEMPLATE.md
  - WRITING_STYLE.md

# Completion Rules

Before marking any lesson as completed, ensure:

- Lesson content is complete.
- Code examples are executable.
- Quiz is included.
- Exercises are included.
- Mini project is included (where applicable).
- Summary is included.
- Next lesson is linked.

---

# Commit Strategy

Commit after each batch of 3–5 lessons.

Example commit messages:

feat(content): add Python lessons 001-005

feat(content): add Python lessons 006-010

feat(content): add ML lessons 001-005

---

# Final Goal

Generate a complete, production-quality AI Engineering curriculum that allows a learner to become job-ready using AI University as the primary learning platform.
